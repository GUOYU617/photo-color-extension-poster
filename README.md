# 实景延伸彩色插画旅行海报

将真实照片制作成2:3竖版旅行海报：上半幅摄影，下半幅为与原图配色协调的原创彩色插画，包含自然连续的场景延伸、小人物互动与大面积象牙白留白。

## 使用

将仓库放入 Codex 的 skills 目录，文件夹名使用 `photo-color-extension-poster`，然后调用：

```text
使用 $photo-color-extension-poster 将上传照片制作成实景延伸彩色插画旅行海报。
```

图像生成依赖独立安装的 `$legacy-imagegen` 技能（Codex CLI 0.128.0，gpt-5.5，独立认证目录）。本仓库不包含该运行时或认证文件。

详细规则与提示词骨架见 [SKILL.md](SKILL.md)。

## 原图保留

生成式编辑可能重构摄影细节。提示词中的保留要求不等于像素级保留已经实现；每张输出需核对尺寸、交界、人物尺度和原图一致性，未验证时标注为生成式预览。
